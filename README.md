# Project 2: Data Tidying and Analysis

**Author:** Sheriann McLarty  
**Course:** IS607 – Data Acquisition and Management  
**Semester:** Spring 2025

## 📂 Project Overview

This project demonstrates how to clean, transform, and visualize messy wide-format datasets using R and the Tidyverse. Three datasets were analyzed:

1. **PRAMS (Pregnancy Risk Assessment Monitoring System)** — Longitudinal health indicators.
2. **DHS Institutional Referrals** — Homeless services referral patterns by gender.
3. **Breast Cancer Cases (2020–2024)** — Age-specific case analysis over time.

## 🛠️ Tools Used

- `tidyverse`
- `janitor`
- `readxl`
- `ggplot2`
- `kableExtra`

## 📊 Outputs

The final report includes:
- Cleaned versions of each dataset
- Visualizations with narrative context
- Reflection on challenges and insights from the tidying process
